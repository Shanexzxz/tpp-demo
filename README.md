# TPP 投资组合管理系统 — 公开 Demo

在线预览：https://shanexzxz.github.io/tpp-demo/

私募股权投资组合管理系统的前端 Demo，覆盖：

- **投资组合** — 11 家被投公司主档 + 9 个详情 Tab（投资/退出明细、现金流、融资与流动性、季度估值、Cap Table、财务指标、委派人员、董事会、审计日志）
- **交易记录** — 全量投资 / 退出 / 分红 / 拆股事件流水
- **基金** — 基金列表与详情（总览 / 持仓组合 / 出资与分配 / 业绩走势），含 Commitment、Paid-in、Dry powder、DPI / RVPI / TVPI、Net IRR
- **总览** — 组合级 KPI、行业与轮次分布、Top Holdings、基金速览
- **后续规划** — 集中说明本 Demo 有意未实现的能力及其数据前提

中英双语切换，USD / CNY 币种切换。

## 说明

- 纯静态单页应用，无框架、无构建、无后端。所有数据为**演示数据**，写操作仅存在于内存，刷新即还原。
- 指标口径以展示为目的：NAV 与成本口径由持仓汇总派生，DPI / RVPI / TVPI 现算；IRR 为演示值，未接入真实 XIRR 计算引擎。详见站内「后续规划」页。
- 本仓库仅托管构建产物，源码与数据管线保留在私有仓库。
